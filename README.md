# View thy irrational world amidst thy rational mind <br> -pi_to_the_one_halvth

I'm Yingkai Nicky Niu, a high-school student from Shanghai (Class of 2028) and co-founder of the PHormation animation club alongside [Tagin_T][1], also known as BeginWithF or Hiverfy_H.

- I'm most active on [Mathematics Stack Exchange][2], discussing analysis, linear algebra, group theory, and other topics. I pose problems, not only just answer them.

- I'm currently working on [real-time-manim][3], a Vulkan-accelerated rendering engine co-written with Tagin_T, designed to push the boundary of ManimCE/GL. It's the base render engine of Manteraction, my concept for an interactive [Manim][4] building app.
